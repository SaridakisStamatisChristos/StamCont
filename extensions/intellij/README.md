## JetBrains integration

The StamCont JetBrains integration provides agent, chat, inline-edit, context, and autocomplete surfaces backed by the same runtime architecture used elsewhere in StamCont.

### Compatibility during the standalone migration

This release stage changes presentation identity only where doing so is safe. The plugin deliberately retains Continue-era plugin, action, tool-window, notification, package, and persisted-settings identifiers where JetBrains or existing installations may depend on the exact value.

Marketplace ownership, artifact naming, signing, and publication remain disabled/deferred until StamCont-owned release infrastructure is defined.
