---
title: "Install StamCont IDE packages"
description: "Install a standalone StamCont GitHub release in VS Code or JetBrains."
---

StamCont standalone releases are installed from artifacts attached to the
StamCont GitHub release. The inherited Continue Marketplace identities remain
compatibility identifiers and are not StamCont-owned publication channels.

<Tabs>
<Tab title="VS Code">

<Steps>
<Step title="Download the VSIX">
Download the artifact matching your platform, for example
`stamcont-vscode-<version>-linux-x64.vsix`, together with `SHA256SUMS`.
</Step>

<Step title="Verify the artifact">
Verify the VSIX SHA-256 digest against the release's `SHA256SUMS`.
</Step>

<Step title="Install from VSIX">
Open the Extensions view, choose **Views and More Actions (...) → Install from
VSIX...**, and select the downloaded `.vsix` file.

You can also use the VS Code CLI:

```bash
code --install-extension stamcont-vscode-<version>-<platform>-<arch>.vsix
```
</Step>

<Step title="Confirm StamCont identity">
The installed extension presents itself as **StamCont**. Continue-era extension,
view, configuration, and command identifiers may remain internally so existing
state and automation continue to work.
</Step>
</Steps>

</Tab>

<Tab title="JetBrains">

<Steps>
<Step title="Download the plugin ZIP">
Download `stamcont-jetbrains-<version>.zip` and `SHA256SUMS` from the
StamCont GitHub release.
</Step>

<Step title="Verify the artifact">
Verify the ZIP SHA-256 digest against the release metadata.
</Step>

<Step title="Install Plugin from Disk">
Open **Settings → Plugins**, open the gear menu, choose
**Install Plugin from Disk...**, and select the downloaded StamCont ZIP.
</Step>

<Step title="Confirm compatibility">
The plugin presents itself as **StamCont** while retaining the compatibility
plugin ID and persisted settings identifiers required by existing installations.
</Step>
</Steps>

</Tab>
</Tabs>
