# StamCont

StamCont is a coding-agent platform centered on a **single canonical runtime** shared across CLI and IDE/GUI surfaces.

Its active development focuses on durable execution rather than a thin assistant shell: deterministic event reduction, persistent sessions, safe resume after interruption, capability-scoped tools, sandboxed execution, long-context compaction, nested sessions, and release-grade cross-platform validation.

## Runtime shape

```text
CLI or IDE/GUI surface
        ↓
provider-neutral AgentModelDriver
        ↓
canonical AgentRunEvent protocol + reducer
        ↓
AgentLoop
        ↓
AgentKernel-authorized tool runtime
        ↓
host / sandbox execution backend
```

## Compatibility note

StamCont originated from [Continue](https://github.com/continuedev/continue) and still contains inherited compatibility surfaces. Technical identifiers such as `~/.continue`, `@continuedev/*`, and `continue.*` may remain until they are intentionally migrated.

Those identifiers are compatibility details; they do **not** mean this repository is the upstream Continue project.
