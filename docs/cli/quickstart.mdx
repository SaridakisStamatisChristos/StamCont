# StamCont CLI

The primary CLI command is `stamcont`. The `cn` command is retained as a compatibility alias. Both use the same runtime.

## Standalone GitHub release

Check [StamCont Releases](https://github.com/SaridakisStamatisChristos/StamCont/releases) for available artifacts. If no release has been published, use the source-build instructions below. Do **not** install `@continuedev/cli` from npm expecting a StamCont release; StamCont retains that package identifier for compatibility but does not own the upstream npm distribution.

For a published `X.Y.Z` release, download `stamcont-cli-X.Y.Z.tar.gz` and `SHA256SUMS` from the **same** release, verify the archive's SHA-256 against the supplied checksum, then extract it:

```bash
tar -xzf stamcont-cli-X.Y.Z.tar.gz
cd stamcont-cli-X.Y.Z
node dist/stamcont.js --help
```

On Windows, after extraction, run `node .\dist\stamcont.js --help` in PowerShell. For the checksum validation and optional global installation, see [CLI README](https://github.com/SaridakisStamatisChristos/StamCont/blob/main/extensions/cli/README.md).

## Build from source

Install Node.js **20.20.1** (as pinned by `.nvmrc`), clone the repository, and run from its root:

```bash
node scripts/build-packages.js
cd core
npm ci
npm run build
cd ../extensions/cli
npm ci --include=optional
npm run build
node dist/stamcont.js --help
node dist/cn.js --help
```

Both help invocations are offline smoke checks and do not require provider credentials. If a local dependency fails to build, consult [build dependencies](https://github.com/SaridakisStamatisChristos/StamCont/blob/main/BUILD_DEPENDENCIES.md) and the component's package scripts.

## Run an agent

After selecting a model/provider and configuring its required authentication, the CLI supports interactive sessions, headless prompts, and session resume:

```bash
stamcont
stamcont -p "Review my current git diff"
stamcont --resume
```

When running directly from a source checkout without a global installation, replace `stamcont` with `node dist/stamcont.js` in the `extensions/cli` directory.

Credentials and external-service behavior depend on the configured model/provider. Continue-era URLs and environment variables may still exist as compatibility surfaces; they are **not** StamCont-owned credentials or distribution services. See [CLI configuration](/cli/configuration) and the [CLI README](https://github.com/SaridakisStamatisChristos/StamCont/blob/main/extensions/cli/README.md) for details.

## Execution authority

StamCont has distinct `Plan`, `Interactive`, and `Full Access` execution profiles. Do not enable Full Access without understanding the OS-user permissions it grants. See [Agent Kernel](https://github.com/SaridakisStamatisChristos/StamCont/blob/main/docs/STAMCONT_AGENT_KERNEL.md) for the security boundary.
