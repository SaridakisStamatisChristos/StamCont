# What is StamCont?

**StamCont is a durable coding-agent runtime and platform** built around one provider-neutral execution path for CLI and IDE/GUI surfaces.

The project is designed for long-running agent work where correctness depends on more than producing a model response. It explicitly models:

- canonical streamed model events;
- authoritative completed tool calls;
- AgentKernel capability enforcement;
- durable append-only session history;
- deterministic replay and safe resume;
- ambiguous-side-effect protection;
- context budgeting and compaction;
- nested agent authority;
- cancellation and owned-process cleanup;
- constrained Plan/Interactive execution and explicit Full Access.

For the release architecture, read [StamCont Agent Runtime](./STAMCONT_AGENT_RUNTIME.md).

For execution and sandbox boundaries, read [StamCont Agent Kernel](./STAMCONT_AGENT_KERNEL.md).

> **Origin:** StamCont began as a fork of Continue and retains inherited code and compatibility identifiers under Apache-2.0. Current StamCont-specific architecture is documented separately and should not be confused with upstream Continue.
